Resumen del plan y de la conversacion
=====================================

Proyecto
--------

El objetivo del repositorio Israelcodigo/club-baloncesto-navalcarnero es preparar una nueva pagina web para el Club Baloncesto Navalcarnero.

La web actual del club es:
https://www.cbnavalcarnero.es/

La referencia conceptual indicada para el rediseno es Manchester Basketball Club:
https://manchesterbasketballclub.co.uk/

La referencia de Manchester se usara solo como inspiracion de estilo, energia deportiva, estructura de contenidos, animaciones, presencia de marca, modulos de partidos/resultados, noticias, sponsors y llamadas a la accion. No se copiara codigo, diseno exacto, textos, imagenes, assets ni identidad visual.

Descripcion del plan
--------------------

El plan propone crear una web moderna, original y mantenible para el Club Baloncesto Navalcarnero. La nueva web debe convertirse en el centro digital del club, con foco en:

- Identidad del CBN.
- Equipos y categorias.
- Cantera y escuela.
- Calendario de partidos.
- Resultados y clasificaciones.
- Noticias y comunicados.
- Inscripciones y pruebas.
- Tienda de ropa del club.
- Pagos online para inscripciones y productos.
- Sponsors y colaboraciones.
- Contacto, ubicacion y formularios.

La direccion visual recomendada es deportiva, local y familiar, usando la identidad propia del club. La proporcion cromatica aprobada para la interfaz es 60% blanco, 30% rojo y 10% negro. La referencia de Manchester aporta energia y estructura, pero la solucion para Navalcarnero debe ser mas ligera, clara y mantenible.

Stack recomendado
-----------------

- WordPress como CMS.
- Tema custom ligero o base tipo GeneratePress / Bricks con plantillas controladas.
- ACF Pro para contenido estructurado.
- Custom Post Types para equipos, jugadores, partidos, sponsors, documentos y noticias.
- WooCommerce para tienda, pedidos, productos de ropa e inscripciones con pago.
- Stripe como pasarela principal recomendada.
- SportsPress solo si aporta valor real para fixtures, resultados y clasificaciones.
- Gravity Forms o Fluent Forms para contacto y formularios no transaccionales, o integracion con WooCommerce para inscripciones con pago.
- GSAP + ScrollTrigger para animaciones selectivas.
- Lenis para scroll suave, con respeto a reduced motion.
- Swiper para carruseles.
- Cloudflare y plugin de cache.
- Buenas practicas SEO, rendimiento, accesibilidad, seguridad y privacidad.

- Clasificaciones.
- Bloques ACF reutilizables.

Futuro:

Riesgos principales
-------------------

- Copiar demasiado la referencia Manchester.
- Sobrecargar la web con animaciones.
- Crear una web dificil de mantener por usuarios no tecnicos.
- Depender demasiado de plugins.
- No tener suficiente contenido real.
- Publicar datos o imagenes sin mantener controles de privacidad, aunque los permisos esten confirmados.
- Dejar desactualizados partidos, resultados o clasificaciones.
- Lanzar pagos sin pruebas de checkout, webhooks, reembolsos, emails y condiciones legales claras.
