# Alineacion visual de home con referencia

Fecha: 2026-06-27

## Referencia

La referencia validada por el proyecto queda guardada en:

```text
docs/redesign/references/home-reference-2026-06-27.jpeg
```

## Uso correcto

La imagen se usa como referencia visual de composicion, ritmo y jerarquia.

No se debe usar como una captura completa pegada en la web porque:

- no seria editable desde WordPress;
- duplicaria navegacion, textos y CTAs dentro de una imagen;
- penalizaria accesibilidad, SEO y responsive;
- impediria conectar datos reales de equipos, partidos, noticias y sponsors.

## Direccion aplicada

La home debe acercarse a la referencia en:

- header blanco compacto con logo, navegacion e inscripcion;
- hero horizontal con titular grande, rojo como acento y visual deportivo a la derecha;
- barra roja de partidos/resultados bajo el hero;
- bloque principal con proximo partido, escuela/equipos y noticias;
- CTAs de tienda e inscripciones inmediatamente visibles;
- franja de patrocinadores antes del footer;
- footer negro con estructura de enlaces;
- proporcion global 60% blanco, 30% rojo y 10% negro.

## Limites

La adaptacion no copia codigo ni assets de terceros. Mantiene el tema WordPress
editable y preparado para conectar contenido real desde ACF, CPTs,
WooCommerce y la futura fuente federativa.
