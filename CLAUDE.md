# Claude Code project guide

Read `AGENTS.md` first. It is the source of truth for project rules, stack, visual constraints and commands.

When using Claude Code on this repo:

1. Explore first.
2. Plan before editing.
3. Implement in small slices.
4. Run `npm run verify`.
5. Do not run multiple agents against the same files at the same time.
6. Keep Manchester Basketball Club as conceptual inspiration only.
7. Keep the website visually aligned to 60% white, 30% red and 10% black.

Useful default prompt shape:

```text
Goal:
Context:
Constraints:
Files likely involved:
Done when:
Verification:
```
